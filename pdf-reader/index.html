Nhập & đẩy dữ liệu lên GitHub

Chọn 1 thư mục sách trên máy (ví dụ create_data/book1) chứa các file chp1.json, chp2.json… Ứng dụng sẽ đọc và đẩy từng file lên repo GitHub vào data/<tên thư mục>/. Chỉ hoạt động tốt trên trình duyệt Chrome/Edge trên Windows/máy tính.

Cấu hình GitHub

Nhập 1 lần, lưu trên máy này. Token tạo tại GitHub → Settings → Developer settings → Fine-grained tokens, chỉ cấp quyền Contents: Read & Write cho đúng repo này.
