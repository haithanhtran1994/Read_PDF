Từ điển tra cứu

Đồng bộ dữ liệu

Quét toàn bộ sách/chương trong thư mục dữ liệu trên GitHub, gom hết ngữ pháp/từ vựng/idiom/slang/collocation/cụm từ vào 1 danh sách tra cứu.

Mục đã ẩn trên app này

Những mục này chỉ bị ẩn trên riêng app tra cứu này — dữ liệu gốc trên GitHub (app đọc sách) không hề bị đụng tới. Bấm "Khôi phục" rồi bấm "Đồng bộ" lại để mục đó hiện lại.

Cấu hình GitHub

Dùng chung repo với app đọc sách. Token cần quyền Contents: Read and write (app này có ghi lại lên GitHub khi dùng chức năng "Sửa", và khi "Xóa" — xóa chỉ ẩn khỏi từ điển này chứ không đụng gì tới dữ liệu gốc grammar/analysis của app đọc sách, danh sách ẩn được lưu thành 1 file JSON dùng chung nên mở từ điện thoại hay PC đều đồng bộ).
